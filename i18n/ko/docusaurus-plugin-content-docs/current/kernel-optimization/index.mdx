# 커널 최적화

커널 최적화는 GPU 커널이 연산 자원, 메모리 대역폭, 온칩 자원을 쓰는 방식을
개선해 커널을 더 빠르고 효율적으로 실행하는 작업입니다. LLM 추론에서는 대개
메모리 이동을 줄이고, 하드웨어 사용률을 높이고, 워크로드를 GPU에 더 세심하게
매핑하는 일을 뜻합니다.
