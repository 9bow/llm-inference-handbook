# LLM 증류(distillation)

[지식 증류(knowledge distillation)](https://arxiv.org/abs/1503.02531)는 더 작은
학생 모델(student model)이 더 큰 교사 모델(teacher model)의 동작을 따라 하도록
학습시키는 모델 압축 기법입니다. 그 결과 더 작고, 더 빠르고, 추론 비용이 더
저렴한 모델을 얻습니다. 더 중요한 점은 이 모델이 교사 모델의 능력을 상당 부분
유지한다는 것입니다.

간단히 이렇게 생각할 수 있습니다.

- 교사 모델은 이미 작업을 잘 해결하는 방법을 알고 있습니다
- 학생 모델은 교사 모델의 출력을 따라 하며 배웁니다

[양자화](/model-preparation/llm-quantization/)는 기존 가중치의 정밀도를
낮추지만, 증류는 완전히 새로운 모델을 만듭니다. 두 기법은 서로 보완적입니다.
증류된 모델을 다시 양자화해 효율을 더 높일 수도 있습니다.

DeepSeek-R1(매개변수 671B)은 증류로 무엇을 할 수 있는지 잘 보여 주는 예입니다.
연구진은 DeepSeek-R1을 이용해 1.5B, 7B, 8B, 14B, 32B, 70B 변형을 포함한 더 작은
모델들에 추론 능력을 전이했습니다. 이 모델들은 교사 모델과 비슷한 방식으로
추론하면서도 추론 비용은 훨씬 적게 듭니다.

## 증류의 동작 방식 {#how-distillation-works}

일반적인 학습에서는 하드 레이블(hard label), 즉 주어진 입력에 대한 정답 하나로
모델을 가르칩니다.

반면 증류에서는 교사 모델의 소프트 레이블(soft label)로 학생 모델을
학습시킵니다. 소프트 레이블은 다음에 올 수 있는 토큰 전체에 대한 확률
분포입니다.

소프트 레이블에는 정답 하나보다 풍부한 정보가 담겨 있습니다. 예를 들어 교사
모델이 "car"에 40%, "vehicle"에 30%의 확률을 부여했다면, 학생 모델은 정답뿐
아니라 어떤 대안이 그럴듯한지, 교사 모델이 얼마나 확신하는지도 함께 배웁니다.
덕분에 학생 모델의 일반화 성능이 좋아집니다.

학생 모델은 보통 다음 두 손실을 조합해 학습합니다.

- **증류 손실**: 학생 모델이 교사 모델의 출력 분포에 얼마나 가깝게 맞춰지는지
  측정합니다.
- **교차 엔트로피 손실**: 레이블이 있는 데이터에 대한 일반적인 다음 토큰
  예측입니다.

두 목적 함수를 조합해 지식 전이와 작업 성능 사이의 균형을 맞춥니다.

## 증류의 종류 {#types-of-distillation}

### 응답 증류 {#response-distillation}

학생 모델이 교사 모델의 출력 토큰 확률에 맞추도록 학습합니다. 교사 모델의
출력에만 접근하면 되므로 가장 흔히 쓰이는 형태입니다. 확장성이 좋아 더 작은 범용
모델을 만드는 데 널리 사용됩니다.

### 특징 증류 {#feature-distillation}

학생 모델이 은닉 상태, 어텐션 패턴, 레이어 활성화 값 같은 중간 표현을 모방하도록
학습합니다. 교사 모델의 내부에 접근해야 하고 구현 비용도 더 크지만, 아키텍처가
비슷한 모델 사이에서는 지식을 더 잘 전이할 수 있습니다.

### 사고 과정 증류 {#chain-of-thought-distillation}

교사 모델이 문제의 단계별 풀이, 즉 전체 추론 과정(reasoning trace)을 생성하고,
학생 모델은 이 추론 과정으로 미세조정됩니다. DeepSeek-R1 증류 변형들이 이
방식으로 만들어졌습니다. 사고 과정 증류는 작은 모델의 추론 능력을 크게
끌어올렸으며, 특히 수학, 코딩, 논리 문제 해결 같은 작업에서 효과가 큽니다.

## 증류를 사용해야 할 때 {#when-to-use-distillation}

다음과 같은 경우 증류가 좋은 선택입니다.

- 지연 시간에 민감하거나 자원이 제한된 배포 환경에서 더 작고 빠른 모델이 필요한
  경우
- 대형 모델을 양자화해도 여전히 VRAM이나 지연 시간 예산을 넘는 경우
- 강력한 교사 모델을 사용할 수 있고 학습 비용을 감당할 수 있는 경우
- 특정 능력(예: 추론이나 코딩)을 더 작은 모델로 옮기고 싶은 경우

다음과 같은 경우에는 증류가 적합하지 않을 수 있습니다.

- 학생 모델과 교사 모델 사이의 능력 차이가 너무 커서 학생 모델의 아키텍처로는
  흡수할 수 없는 경우
- 학습 중에 교사 모델의 추론을 실행할 연산 자원이 없는 경우
- 기존 모델을 양자화하거나 미세조정한 버전으로 이미 요구 사항을 충족하는 경우
- 가능한 최대 정확도가 필요한 경우

:::note
모든 모델을 증류할 수 있는 것은 아닙니다. 일부 라이선스는 모델 출력을 다른
모델의 학습에 사용하는 것을 금지합니다.
:::

## 증류가 추론에 미치는 영향 {#how-distillation-impacts-inference}

증류는 학습 단계에서 이루어지지만, 그 효과는 추론 단계에서 나타납니다.

증류로 더 작은 모델을 만들면 서빙 효율이 직접 개선됩니다.

- **낮은 지연 시간**: 토큰 생성이 빨라집니다
- **적은 메모리 사용량**: GPU 메모리가 덜 필요합니다
- **높은 처리량**: 같은 하드웨어에서 더 많은 요청을 병렬로 처리할 수 있습니다
- **낮은 비용**: 요청당 필요한 연산이 줄어듭니다

즉, 증류는 런타임 최적화를 적용하기 전부터 추론의 기본 비용을 낮춥니다.

다음과 같이 생각할 수 있습니다.

- 증류는 모델을 더 작게 만듭니다
- 양자화는 모델을 더 가볍게 만듭니다
- [추론 최적화](/inference-optimization/)(예:
  [프리픽스 캐싱](/inference-optimization/prefix-caching/))는 서빙을 더
  효율적으로 만듭니다

추론 시스템에서 이 기법들을 조합할 수 있습니다. 대형 모델 → 증류 → 더 작은 모델
→ 양자화(필요한 경우) → 서빙 최적화 → 배포

## 자주 묻는 질문 {#faqs}

### 증류의 주요 과제는 무엇인가요? {#what-are-the-main-challenges-of-distillation}

증류는 효과적일 수 있지만 다음과 같은 트레이드오프가 있습니다.

- 추가 학습 연산이 필요합니다
- 교사 모델의 품질에 좌우됩니다
- 복잡한 작업에서 성능이 떨어질 수 있습니다
- 데이터 생성과 필터링을 신중하게 해야 합니다

그래서 많은 팀이 양자화부터 시작하고, 필요할 때만 증류를 사용합니다.

### 증류와 양자화의 차이는 무엇인가요? {#what-is-the-difference-between-distillation-and-quantization}

두 기법을 나란히 비교하면 다음과 같습니다.

|                        | 증류                       | 양자화                             |
|------------------------|----------------------------|------------------------------------|
| **바꾸는 것**          | 새롭고 더 작은 모델을 학습 | 기존 모델의 정밀도를 낮춤          |
| **결과물**             | 다른 모델(학생 모델)       | 같은 모델, 더 낮은 정밀도의 가중치 |
| **적용 시점**          | 학습 중                    | 학습 후                            |
| **필요한 연산량**      | 많음, 학습이 필요          | 적음, 빠르게 적용 가능             |
| **크기에 미치는 영향** | 매개변수 수를 줄임         | 매개변수당 메모리를 줄임           |
| **사용 난이도**        | 더 복잡함                  | 적용하기 쉬움                      |
| **대표적인 사용 사례** | 더 작은 프로덕션 모델 구축 | 기존 모델을 배포용으로 최적화      |
